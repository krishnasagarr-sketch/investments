Backup

Everything lives on this device, with no server or cloud copy — losing the device loses the data. The full backup is one .zip holding your records and every attached document (statements, receipts, notices, the kept locked originals, Mail Scan's saved attachments). Download one regularly, especially before a phone reset, app reinstall, OS update, or a reset below. It contains personal financial information — keep it somewhere private.

Download full backup (.zip)

Records only, no documents: download the database (.db).

Restore

Replaces everything currently in the app with the contents of the backup file — a full backup (.zip) brings back the records and the documents; a database-only (.db) file brings back just the records. What's here now is kept automatically before restoring (a dated safety copy next to the database), in case this wasn't what you meant to do.

Reset — clear all data and start again

For when you've finished building and testing and want to replace the test data with real data. This empties every record and removes every saved document, and numbering starts again at 1. It can't be undone unless you keep the safety copy below — so download a full backup first.
