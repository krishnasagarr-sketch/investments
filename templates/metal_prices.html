Gold (24K & 22K) and Silver use IBJA's daily reference rate — the same benchmark Indian jewellers and banks price against, via a community-run API. It already includes import duty, GST and the local market premium, so it reads higher than a plain international spot conversion — that's expected, and is what makes it the actual Indian market price. Platinum and Palladium aren't published by IBJA, so those still use the global spot rate from gold-api.com converted via the live USD→INR rate. "Other" has no live source — set it by hand.
